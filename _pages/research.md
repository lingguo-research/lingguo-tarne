# Research

My research focuses on software measurement and software estimation, with particular interests in COSMIC functional size measurement, early software sizing, software size–effort relationships, and software engineering education.

## Research Interests

- Software Measurement
- Software Estimation
- COSMIC Functional Size Measurement
- Early Software Sizing
- Software Size–Effort Relationships
- Software Engineering Education
- Educational Games for Software Engineering

## Current Research

### Early Software Sizing

Investigating techniques for estimating software functional size from early and incomplete software requirements.

### Software Size and Effort Estimation

Studying the relationships between software functional size, effort, and estimation methods.

### Software Engineering Education

Designing and evaluating educational games for teaching software estimation concepts and decision-making.

### COSMIC Functional Size Measurement

Applying the COSMIC ISO standard to software applications, software generators, software evolution, and estimation-related case studies.
