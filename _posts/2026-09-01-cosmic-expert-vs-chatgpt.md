# Comparing COSMIC Functional Size Measurement: Expert vs. ChatGPT

## Introduction

Functional Size Measurement (FSM) is an important activity in software engineering because it enables organizations to estimate software size based on the functionality delivered to users rather than on implementation details such as lines of code.

The COSMIC method is an internationally standardized functional size measurement method. It measures software functional size based on the data movements associated with functional processes.
