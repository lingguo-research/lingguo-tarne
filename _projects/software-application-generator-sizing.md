This project applies the COSMIC functional size measurement method to the SimSE educational game generator.

The study investigates the functional size of a software application generator and its generated software products, providing insights into the functional sizing of generator-based software.

**Research focus:** COSMIC · Functional size measurement · Software generators · SimSE
